# 🦕 Тренажёр ЕГЭ по русскому языку

Интерактивный тренажёр в формате **Telegram Mini App** для эффективной подготовки к экзамену по русскому языку (Задания **№4** и **№9**).

---

## ✨ Возможности приложения

- 📝 **Задание №9 — Словарные слова**: 537 официальных слов по актуальному кодификатору ФИПИ (все непроверяемые гласные корня).
- 🔤 **Задание №4 — Ударения**: 240 слов с нормативными ударениями из официального орфоэпического словника.
- 🎯 **Гибкие фильтры**:
  - Выбор длины сессии (10, 20, 30 или все слова).
  - Тренировка по начальным буквам алфавита (по одной или нескольким).
  - Тренировка по частям речи (глаголы, существительные, прилагательные и др.).
- 🔄 **Отработка ошибок**: мгновенный повтор допущенных ошибок сразу после тренировки или со страницы статистики.
- ⭐ **Избранное**: сохранение трудных слов в персональный список в один клик.
- 📖 **Интерактивный словарик**:
  - Быстрый поиск в реальном времени.
  - Алфавитная лента быстрого выбора буквы.
  - Сортировка по первой букве (А–Я) и по частям речи.
- 📊 **Статистика и аналитика**:
  - Подсчёт процента точности и общего количества решённых слов.
  - Список топ-проблемных слов.
  - История последних тренировок.
- 📱 **Современный интерфейс**:
  - Адаптивный дизайн для мобильных устройств и десктопа.
  - Полная поддержка светлой и тёмной темы Telegram.
  - Анимации и тактильный отклик (Haptic Feedback).

---

## 🔒 Безопасность и конфиденциальность

- Все данные и прогресс пользователей изолированы и сохраняются локально на устройстве каждого ученика через Telegram WebApp Sandbox.
- Прогресс одного пользователя никогда не смешивается с прогрессом другого.
- Секретные ключи и токены хранятся исключительно на стороне сервера и не передаются в клиентскую часть.
